# BONC DSS Statistics — 专业统计分析产品家族

BONC DSS Statistics 是由北京东方国信科技股份有限公司基于 IBM SPSS Statistics 推出的专业统计分析软件，广泛应用于科研、教育、企业和政府领域。通过图形化操作界面和强大的统计建模能力，帮助用户高效地进行数据分析、建模与预测。

产品家族提供 **三种形态**，覆盖「单机统计 → 自然语言统计 Agent → 多 Agent 协作编排」的三层能力：

| | BONC DSS Statistics 桌面版 | BONCML AI Agent（AutoDL 云端版） | BONCML Workspace（多 Agent 协作平台） |
|--|---------------------------|--------------------------------|--------------------------------------|
| 交互方式 | 图形化拖拽界面，菜单操作 | 自然语言对话，AI 自动推荐并执行 | Spec 驱动的多 Agent 协作，自然语言 + 频道编排 |
| 操作系统 | Windows、Linux | 云端运行（AutoDL），本地浏览器访问 | 云端运行，浏览器访问工作空间 |
| 适合用户 | 习惯 SPSS 图形界面的用户 | 希望用自然语言快速分析的用户 | 需要多人多 Agent 协同完成复杂任务的团队 |
| 部署方式 | 本地安装 | 云镜像一键启动 | 云端工作空间 |
| 能力定位 | 统计算法执行 | 单一统计 Agent 自动分析 | 编排需求/方案/评审/算法等多个 Agent 协同交付 |

三者既可独立使用，也可组合：**Workspace** 可将统计分析、方案撰写、评审等任务组织成 Spec → Issue → DAG → Artifacts 的流水线，调度包含统计 Agent 在内的多个智能体协同完成端到端任务。

## 功能概述

覆盖以下统计分析领域：

- **数据管理** — 支持多格式导入（Excel、CSV、SPSS `.sav`），具备数据清洗与转换能力
- **描述性统计** — 快速生成均值、方差、偏度、峰度、频率分布、交叉表等
- **推断分析** — t 检验、方差分析（ANOVA）、卡方检验、非参数检验等
- **回归与建模** — 线性回归、加权回归、对数线性模型等
- **聚类与分类** — K-Means 聚类、K 近邻分类
- **时间序列与生存分析** — 自相关分析、时间序列变换、寿命表、Kaplan-Meier
- **问卷与实验设计** — 多重响应分析、正交设计
- **可视化** — 内置可视化输出（箱线图、聚类条形图等，持续扩展中）
- **多 Agent 协作编排（Workspace）** — Spec 驱动的任务编排，需求澄清、方案设计、DAG 调度、评审交付全流程自动化

完整的 45 个算法命令清单详见 → [支持的统计分析能力（45 个算法）](./ALGORITHMS.md)

## 软件优势

| 优势 | 说明 |
|------|------|
| 可视化操作（桌面版）| 拖拽式图形界面，低代码操作，适合非程序员使用 |
| 自然语言交互（AI 版）| 用日常语言描述分析需求，AI 自动推荐方法并执行 |
| 强大算法库 | SPSS 兼容统计算法，结果精确可靠，与 SPSS 输出对齐 |
| 高兼容性 | 支持 CSV、TSV、Excel、SPSS `.sav` 多种数据格式，可与 Python、数据库系统集成 |
| 智能推荐（AI 版）| 根据数据结构和语义检索自动推荐合适的统计方法 |
| Spec 驱动协作（Workspace）| 以 Spec 为协作核心，需求 Agent 澄清、多 Agent 按 DAG 并行、评审 Agent 把关 |
| 多 Runtime 可观测（Workspace）| 对接 Copilot/Claude/Hermes 等执行引擎，实时追踪 Token 与费用 |
| 无 GPU 依赖 | 统计计算基于 CPU，适合低成本部署 |

## 支持的数据格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| CSV | `.csv` | 推荐使用，兼容性最好 |
| TSV | `.tsv` | 自动识别制表符分隔 |
| Excel | `.xlsx` / `.xls` | 需 openpyxl 支持 |
